# Asset list & creation guide

Every asset Stage 1 needs **already exists as a working placeholder** (generated by `tools/`), so the
mod runs out of the box. Replace them one by one with hand-made versions, keeping names, sizes and layouts.

Palette (use everywhere): deep red `#6B0A08`, crimson `#C7201A`, burning orange `#FF6E12`,
gold `#FFCD5A`, white-hot `#FFF6E1`. Blade steel: near-black `#0C0B0E`, spine `#222126`, edge line `#585460`.

## 1. Nichirin Blade (GeckoLib)

| File | Size | Notes |
|---|---|---|
| `geo/item/nichirin_blade.geo.json` | 32×32 texture space | Bones: `root` → `handle`, `guard`, `blade`. Keep the **`blade`** and **`guard`** bone names (used by the ignite animation). |
| `textures/item/nichirin_blade.png` | **32×32** | Base texture, black steel. Transparent pixels are cut out. |
| `textures/item/nichirin_blade_glow.png` | **32×32** | Emissive mask, **same UV layout**. Black = no glow. Paint only the blade (crimson at the guard → orange at the tip, gold/white on the cutting edge). Rendered additively and faded in by Total Concentration. |
| `animations/item/nichirin_blade.animation.json` | – | `animation.nichirin_blade.ignite` (0.5s flare when Total Concentration starts). |
| `models/item/nichirin_blade.json` | – | `builtin/entity` + display transforms (hand/GUI/ground positions). |

Current UV layout (per-face UV, pixels):

| Region | Origin | Size | Used by |
|---|---|---|---|
| Blade broad face | 0,0 | 4×17 | column 0 spine, 1–2 body, 3 cutting edge |
| Blade tip face | 0,17 | 4×2 | tip cube |
| Blade thin edge | 4,0 | 1×17 | edge faces, top/bottom |
| Habaki (collar) | 6,0 | 2×2 | gold |
| Tsuba top/bottom | 8,0 | 6×6 | round guard |
| Tsuba rim | 8,6 | 6×1 | guard sides |
| Handle wrap | 14,0 | 4×8 | diamond wrap |
| Handle caps | 14,8 | 2×2 | |
| Pommel | 18,0 | 3×3 | |

### Blockbench workflow
1. Install the **GeckoLib Animation Utils** plugin (File → Plugins). Create a new **GeckoLib Animated Model**, type *Item*.
2. File → Import → open `geo/item/nichirin_blade.geo.json` to start from the existing proportions,
   or model from scratch: blade ~17px long along +Y, 1.5px wide (X), 0.5px thick (Z); handle 8px; guard 5×5.
   Keep the handle bottom at the origin and the blade along +Y.
3. Set texture size 32×32 (or 64×64 for more detail; update `texture_width/height`). Use **per-face UV** for thin pieces.
4. Paint the base texture: near-black with a slightly lighter spine and a thin grey hamon line on the edge.
5. Duplicate the texture, fill everything black, then paint only the blade in the glow palette → save as `_glow`.
   Tip: a 1px brighter edge line plus a soft vertical gradient reads best at small sizes.
6. Animate: in the Animate tab create `animation.nichirin_blade.ignite` (0.5s): scale the `blade` bone to ~1.35 on X/Z at 0.08s
   and ease back; optional guard twist. Export: File → Export → *GeckoLib Animations*.
7. Export the model (*Export GeckoLib Model*) to `geo/item/` and the display settings (*Export Display Settings*)
   to `models/item/nichirin_blade.json` (keep `"parent": "builtin/entity"`).
8. Tune the **Display** tab: third-person right hand, first-person right hand, GUI (diagonal, tip up-right), ground.
   The shipped values are reasonable guesses; this is the first thing to fix in-game.

## 2. Player animations (Player Animator, GeckoLib format)

| File | Animation name (lookup key) | Length |
|---|---|---|
| `player_animation/form_dance.json` | `form_dance` | 0.6s |

Name convention for later forms: `form_<form key>`, e.g. `form_clear_blue_sky`, `form_raging_sun`.
Bones: `head`, `torso`, `right_arm`, `left_arm`, `right_leg`, `left_leg`, `body` (whole body), `right_item`, `left_item`.
Rotations are degrees; only keyed bones override the vanilla pose, so legs keep walking unless you key them.

### Blockbench workflow
1. Install the **Player Animator / Emotecraft** Blockbench plugin, or use any rig whose bones use the names above.
2. Animate at **20 fps** (Minecraft ticks). Keep key poses on tick boundaries (0.05s steps).
3. Dance timing contract (`forms/FormTiming.java`): windup peak at 0.10s, blade crosses the target at **0.15s**
   (server hit check, tick 3), follow-through to 0.30s, recover by 0.60s. Retime → update FormTiming.
4. Export as GeckoLib/Bedrock animation JSON into `player_animation/`.

## 3. Particle textures (white + alpha; tinted in code)

All live in `textures/particle/`; frame lists are in `particles/*.json`.

| File | Size | Description |
|---|---|---|
| `sun_flame_0` … `sun_flame_5` | **16×16** ×6 | Flame wisp lifecycle: solid teardrop (0) → licking, broken (3) → wispy remnants (5). |
| `sun_ember_0`, `sun_ember_1` | **8×8** ×2 | Tiny hot dot, soft edge. |
| `sun_ray` | **16×16** | Horizontal streak: bright at **left** (head) fading to the right; thin Gaussian across. |
| `sun_flash` | **32×32** | Radial bloom with 6 soft spikes. |
| `sun_glow` | **16×16** | Very soft radial puff (aura). |

Paint them **white** on transparent; intensity = alpha. Colour comes from the shared palette in
`SunPalette`, so they stay consistent and still get the white-hot → deep-red ramp.

## 4. Shaders

`shaders/core/slash_glow.{json,vsh,fsh}`: the slash ribbon shader (additive, animated flame edge,
white-hot core). No art needed. Disable with `glowShader = false` if a shaderpack misbehaves.

## 5. Sounds (all **mono .ogg**, 44.1 kHz, Vorbis q5+)

Stage 1 ships procedural placeholders. To replace, keep the path and filename.

| Event | Files (`sounds/…`) | Length | What it should be |
|---|---|---|---|
| `form.dance.swing` | `form/dance_swing1`, `dance_swing2` | 0.3–0.45s | Fast, airy blade whoosh with a faint steel "shing". Swish, not roar. |
| `flame.ignite` | `flame/ignite1`, `ignite2` | 0.4–0.6s | "Fwoomp": gas-burner ignition, low body, quick bloom. |
| `flame.crackle` | `flame/crackle1..3` | 0.5–0.8s | Bright fire crackle/pops, no low end (sits on top of impacts). |
| `impact.slash` | `impact/slash_hit1..3` | 0.25–0.4s | Sharp cut: transient + short metallic ring + flesh/cloth body. |
| `impact.sub` | `impact/sub_hit1`, `sub_hit2` | 0.4–0.6s | Sub-bass thump 30–90 Hz, pitch dropping. Felt more than heard. |
| `blade.ignite` | `blade/ignite` | 0.7–1.0s | Rising flame roar + crackle + high shimmer as the blade lights. |
| `breath.loop` | `breath/concentration_loop` | 3–5s, **seamless loop** | Calm, deep in-breath → pause → controlled out-breath. Quiet. Start and end on silence. |
| `breath.inhale` | `breath/inhale` | ~0.9s | Sharp, focused inhale through the teeth. |
| `breath.exhale` | `breath/exhale` | ~1.0s | Long release. |
| `breath.fail` | `breath/fail` | ~0.5s | Short gasp(s), out of breath. |
| `ui.open` | `ui/wheel_open` | ~0.3s | Soft whoosh + low chime. |
| `ui.select` | `ui/select` | <0.1s | Tiny bright tick/chime. |

Sourcing tips: Freesound.org (check CC0/CC-BY licences), Sonniss GDC bundles (royalty-free), or record:
swinging a thin stick/cable for whooshes, a gas lighter/torch for ignites, crumpling cellophane for crackle,
a cabbage/leather hit for impact bodies, and a synth sine drop for the sub. Normalise each to ~-1 dBFS peak;
the code mixes the layers (impact 1.0, sub 0.6–1.1, crackle 0.7).

Later forms will each add their own `form.<key>.swing` layer (and some, e.g. Fire Wheel and Beneficent
Radiance, a unique signature layer); impact/sub/crackle are shared.
