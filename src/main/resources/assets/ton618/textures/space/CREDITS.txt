Earth textures (4096 x 2048), repacked for the space shader

earth_day_clouds.png
    RGB: NASA Blue Marble Next Generation with topography and bathymetry (NASA Earth Observatory), public domain.
         Source file via the three-globe project (vasturiano/three-globe), MIT licence.
    A:   cloud cover, NASA Blue Marble cloud layer (NASA Goddard / Visible Earth), public domain.
         Source file via the webgl-earth project (turban/webgl-earth).

    RGB: city lights isolated from NASA Earth Observatory "Earth at Night" (Black Marble), public domain.
         Source file via vasturiano/three-globe.
    A:   ocean mask, NASA Blue Marble derived, via turban/webgl-earth.
earth_height.png
    Elevation (bump) map, NASA / GEBCO derived, via turban/webgl-earth.
